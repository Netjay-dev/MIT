b.	Is the algorithm in the code more closely related to insertion-sort or selection-sort? In what way does it differ from that?
It's a selection sort algorithm since it always looks for the smallest element on the right side of the array and it scans all the ith + 1 remaining elements, while insertion sort stops when ith - 1 element is lesser than or equals to ith element. The insertion sort algorithm is more like starting at the second element and comparing it to the element backward or to left. The direction of comparison differs, and the execution time differs to since insertion sort might have the lesser execution time since it has a condition to stop.
